# Recursos del gemelo digital

El repositorio oficial de Unitree mantiene el modelo MJCF y las mallas del G1 en `unitree_mujoco`. Para obtener una copia local:

```bash
git clone --depth 1 https://github.com/unitreerobotics/unitree_mujoco.git assets/unitree_mujoco
```

El modelo se encuentra en `assets/unitree_mujoco/unitree_robots/g1/`. La documentación oficial también publica una imagen de referencia de la arquitectura del simulador:

- [Diagrama oficial del simulador](https://raw.githubusercontent.com/unitreerobotics/unitree_mujoco/main/doc/func.png)
- [Repositorio oficial Unitree MuJoCo](https://github.com/unitreerobotics/unitree_mujoco)

La fuente declara licencia BSD-3-Clause. Se conserva el enlace y no se copia el binario en este repositorio para mantenerlo liviano y trazable.
